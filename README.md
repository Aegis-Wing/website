# Aegis Wing website

The website is built with Next.js App Router, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js. Create a production build with `npm run build`, then serve it with `npm start`.

## Current implementation stage

The current page contains the navigation and hero only. The remaining page sections are intentionally waiting for design feedback before implementation.

## Brand and content notes

- The hero uses the existing Aegis eagle silhouette and shield mark from `public/`.
- The public repo should not add unverified certifications, delivery guarantees, client results, or contact details.
- Contact and lower-page navigation destinations will be wired when their sections are built.
