# Aegis Wing design direction

## Current build stage

The Next.js App Router implementation currently contains only the navigation and hero, matching the requested staged build. Pause here for feedback before building lower-page sections.

## Visual system

- Printed intelligence dossier on warm paper `#F2EEE6` with navy ink `#05182B`.
- Single vivid red `#D90B0B` reserved for the CTA, one emphasized headline word, and restrained detail.
- Muted body copy `#5B6575`; fine rules use navy at 18% opacity.
- Instrument Serif headlines, Inter body text, JetBrains Mono labels.
- Flat surfaces, hairline rules, visible hero column grid, and restrained paper grain. No gradients, glows, or shadows.
- Hero message: “We break in / so they / can’t.” with the available Aegis eagle silhouette and red shield.
- No invented certifications, delivery guarantees, client results, or contact details.
